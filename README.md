# Demo project

Static HTML/CSS/JavaScript prototype. Open `index.html` or run `python -m http.server 8000` from this folder.

Before client launch, replace the fictional Ironform brand, sample content, phone/WhatsApp number `919000000000`, imagery, address, hours, social links, map, and any sample membership/trainer/timetable data with client-approved information. Add the client's GA4 Measurement ID only after privacy/consent review. No backend, database, authentication, payments, booking, CRM, automated WhatsApp or AI feature is included.
